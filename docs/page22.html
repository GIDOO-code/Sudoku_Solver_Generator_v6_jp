  問題のクラス(UPuzzle)

    問題クラス
  • GNPX(ver 7-)には、問題クラスは2種類あります。
  • 1つは、問題リスト用のクラスです。
    ファイルから入力した数独問題や、GNPXが生成した問題を保持します。このため、少数の要素のみの簡単なクラスです。
  • 2つ目は、解析アルゴリズムで使う問題クラス(UPuzzle)です。
    解析アルゴリズムに用いる様々な要素を持つクラスです。解析を始める時点で実体化し、解析が終了したらオブジェクトを破棄します。 解析アルゴリズムの実行中に、オブジェクトをコピーすることもあります。 1つの問題の解析中に生成する全オブジェクトは、rootオブジェクトに紐づけて保持します。
    UPuzzleクラス
  • 最初の4要素は、問題の連続番号(ID)、名前(Name)、作成時刻(TimeStamp)、解読時のコメント(solMessage)で、全て識別用の項目です。 解析アルゴリズムには関係しません。
  • DifficultyLevelは問題の難易度です。これはヒトが解くときの難易度ではありません。以下の解析アルゴリズムでは、 プログラムで調べるのは簡単だがヒトがそれを発見するのは極めて困難な方法が、たくさん出てきます。 そこでの複雑さをもとに適当に (主観的な適切度で）定めたものです。なお、人手で解けるのはレベル1,2,3,4くらいまでです。 今のところ、レベル10ほどまで割り振っています。
  • BOARDは問題を表す81セル(UCellクラス)のListです。
public class UPuzzle{
	public int     ID;
	public string  Name;
	public string  TimeStamp;
	public string  solMessage;

	public int     DifficultyLevel;    //-1:初期状態 0:手動作成
	public bool    Insoluble;    //解なし
	public List<UCell> BOARD;

	public UPuzzle( ){
		ID=-1;
		BDL = new List<UCell>();
		for( int rc=0; rc<81; rc++ ) BOARD.Add(new UCell(rc));
		this.DifficultyLevel = 0;
	}
	public UPuzzle( List<UCell> BOARD ){
		this.BOARD  =  BOARD;
		this.DifficultyLevel = 0;
	}
	public UPuzzle( int ID, List<UCell> BOARD, string Name="", int DifLvl=0 ){
		this.ID = ID;
		this.BOARD = BOARD;
		this.Name = Name;
		this.DifficultyLevel = DifLvl;
	}

	public UPuzzle Copy( ){
		UPuzzle SDP = (UPuzzle)this.MemberwiseClone();
		SDP.BOARD = new List<UCell>();
		foreach( var P in BOARD ) SDP.BOARD.Add(P.Copy());
		return SDP;
	}
}
